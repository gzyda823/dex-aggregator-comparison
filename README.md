## DEX aggregator 是什么，和直接用 DEX 有什么区别？

DEX（去中心化交易所）通常通过流动性池或其他链上机制完成代币兑换。DEX aggregator 则会查询多个可用交易来源，估算不同路径的结果，并向用户展示一条或多条兑换路线。部分交易可能拆分到多个池子或平台执行，以改善整体报价。

直接在某个 DEX 交易，路径通常集中在该平台的流动性上；使用聚合器，则多了一层路线搜索。它能减少逐个平台手动查价的工作，但不会消除链上交易本身的成本和风险。网络拥堵、池子深度不足、代币价格波动，都可能让实际成交结果偏离初始报价。OKX 的帮助文档说明，其路由会模拟不同路径的结果，并考虑预计到账金额和 gas 成本；在多条路线可用时，也可能拆分订单。

简单说，聚合器帮你比较和组织交易，不会让低流动性代币突然变得好卖，也不代表报价确认后就永远不变。

## 如何判断聚合器报价是否划算？

看报价时，先关注“预计收到多少”，再看费率名称。一个界面服务费较低的路线，如果 gas 更贵或价格影响更大，最终未必更划算。反过来，显示更高名义费率的路线，也可能因为路径更深而提供更好的净到账结果。

建议在确认前按这个顺序核对：

1. **确认网络和代币合约。** 同名代币可能在不同链上存在，也可能有仿冒资产。通过合约地址辨认资产，不要只凭代币名称或图标。
2. **比较预计到账量。** 如果有多个路线或模式，检查扣除可见费用后的结果。对大额兑换尤其如此。
3. **留意滑点和最小到账量。** 滑点容忍度过低可能导致交易失败；调得过高，则可能接受比预期更差的成交价。
4. **检查网络费和钱包授权。** 某些代币首次交易需要先授权合约，授权本身也可能产生网络费。
5. **确认交易模式。** 即时兑换、限价单、意图交易或跨链路线的执行方式不同，不应只比较一个数字。

OKX 支持动态、固定和有上限的滑点设置。其帮助中心也提醒，交易失败仍可能产生网络费，因为网络已经处理了交易请求；因此，为省一点 gas 而盲目选择过低费用，不一定是好主意。

## 常见问题

### DEX aggregator 一定比直接在 DEX 兑换便宜吗？

不一定。聚合器会搜索可用路线，但市场价格、流动性、gas 和接口费都会影响净结果。最可靠的做法是在同一时间比较预计到账数量，并确认费用构成。不同时间取得的报价不能直接当作公平对比，因为链上状态可能已经变化。

### 为什么实际成交价和报价不完全一样？

报价到交易进入区块之间，池子里的流动性可能变化，其他交易也可能先影响价格。OKX 的帮助文档将滑点、池子变化和网络拥堵列为报价与实际成交结果不同的原因。滑点保护能限制接受的价格变化，但也可能让交易无法执行。

### 交易失败还会扣费吗？

可能会。网络费支付给区块链验证者或处理交易的网络，并非所有交易失败都能退回这部分费用。是否需要重新发起、调整网络费或检查授权状态，应先查看钱包中的交易详情。

### 这个聚合器有月费套餐吗？

OKX DEX 的官方费用信息以每笔交易的接口费率等项目为主，未显示需要订阅的月费套餐。因此不适合制作传统“Basic、Pro、Enterprise”式套餐表。交易前应逐笔查看预览页的费用；不同代币组合和路线可能适用不同规则。citeturn3view0
